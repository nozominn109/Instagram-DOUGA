## 絵（ChatGPT）
### 絵1：ドリルとスマホ
```
添付の絵と同じ田中家のリビングの大理石の丸テーブルで、莉奈（茶髪ポニーテール、ピンクのトレーナー）が算数ドリルを開いて、スマホを手に「AIに聞いちゃお」といたずらっぽい顔をしている。となりに座った愛奈（ラベンダーのカーディガン）が、やさしく「待って」と手を軽く上げている。ドリルの中の文字は描かないでください（白いページにしてください）。午後のやわらかい光。室内なので靴なし。ジブリ映画のような手描きアニメ、水彩タッチ。2人の顔が見えるように、頭の上に少し余白。縦長（9:16）、文字は入れないでください。手は1人2本ずつ。
```
### 絵2：ドリルに書きこむ莉奈（マークアップで作る）
```
添付の絵と同じ場面で、莉奈がえんぴつを持ってドリルに一生けんめい書きこんでいる、集中した顔。愛奈はとなりでやさしく見守っている。ドリルの文字は描かないでください。ほかは変えないでください。
```
### 絵3：自分で解けた！（マークアップで作る）
```
添付の絵と同じ場面で、莉奈が両手を上げて「やった！」とうれしそうに笑っている。愛奈は笑顔で莉奈を見て、ほめている。ほかは変えないでください。手は1人2本ずつ。
```

## キャプション
```
宿題、AIにやらせたらズル？🤔

答えを聞くだけなら、ズルかも。
でも「答えは言わないで、ヒントだけ」とお願いすれば、AIは一緒に考える相棒になります。

自分で解けたときの「わかった！」は、答えをもらうより、ずっとうれしい。

📝 そのまま使えるお願いの文（保存してね）
「小学5年生の算数の宿題です。答えは言わずに、考え方のヒントを1つずつ出してください。私が答えたら、合っているか教えてね」
※小学生のうちは、親と一緒に使ってね（多くのAIは13歳以上が対象です）

一緒に子育てしている人に送ってね。
```
