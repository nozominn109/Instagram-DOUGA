# 時短AI ①「今日のごはん何？」（11/9 20:00投稿予定・15秒）制作キット（たたき台）

新シリーズ「時短AI」（目標設定セッションで希さんがOK）。10〜15秒の超ショート、家族全員の掛け合い、1人1秒のテンポ。お願いの文はキャプションへ。

| 秒 | 場面 | 声・文字 |
|---|---|---|
| 0〜2 | 食卓（夕方）全員 | 文字「毎日の『今日のごはん何？』問題…」 |
| 2〜3 | 蒼アップ | 蒼「肉！」 |
| 3〜4 | 莉奈アップ | 莉奈「パスタ！」 |
| 4〜5 | 哲アップ | 哲「…なんでもいい」 |
| 5〜7 | 愛奈アップ（希亜を抱っこ） | 愛奈「それがいちばん困るの！」チャッピー「ワン！」 |
| 7〜10 | スマホ画面 | AIの3案（ガッツリ肉／パスタ／さっぱり） |
| 10〜13 | 食卓・全員で指さし | 全員「これ！」 |
| 13〜15 | 哲と愛奈 | 哲「…で、俺は何すればいい？」愛奈「お皿洗い」→ フォロー誘導 |

- 家の中なので全員靴なし。希亜は抱っこで映す。
- 使い回し候補：蒼・莉奈・哲・愛奈のアップは、新しい食卓の絵1枚から顔を切り出してズームでも作れる（Klingを減らすなら）。
