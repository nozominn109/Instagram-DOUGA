## 絵（ChatGPT）※時短AI①の食卓の絵（1枚目）を添付。席順は左から哲・蒼・莉奈・愛奈で同じに
### 絵1：しーんとした食卓
```
添付の絵と同じ田中家のダイニング、同じ席順（左から哲・蒼・莉奈・愛奈）で、テーブルには夕ごはんの「ガッツリ鶏の照り焼き丼」が全員分とみそ汁が並んでいる。全員が席に座っている。哲はテレビのほうをぼんやり見ている。蒼は頬づえをついてスマホを見ている。莉奈はぼんやり遠くを見ている。愛奈は希亜をひざに抱いて、少しさみしそうに家族を見ている。足もとのチャッピーだけがこちら（画面）を見ている。静かな雰囲気。室内なので全員靴なし（靴下・スリッパ）。夕方のあたたかい光。ジブリ映画のような手描きアニメ、水彩タッチ。全員の顔が見えるように、頭の上に少し余白。縦長（9:16）、文字は入れないでください。
```
### 絵2：愛奈がこっそりスマホ（マークアップで作ると席順が崩れない）
```
添付の絵と同じ場面で、愛奈だけ、テーブルの下でこっそりスマホを見ている。少し考えこむ表情。ほかの家族・席順・部屋は変えないでください。
```
### 絵3：会話がはずむ食卓（マークアップで作る）
```
添付の絵と同じ場面で、家族みんなが楽しそうに話している。莉奈は笑顔で身を乗り出し、哲は大笑い、蒼はスマホをテーブルに置いて頬づえのまま少し照れて笑う、愛奈はうれしそうにほほえむ。チャッピーもしっぽを振る。席順・部屋は変えないでください。手は1人2本ずつ。
```
