## 絵（ChatGPT）※時短AI①の食卓の絵を添付
### 絵1：夜10時のリビング
```
添付の絵と同じ田中家のリビング、夜10時。窓の外は夜景。部屋はフロアランプのあたたかい明かり。ソファに座る愛奈（ラベンダーのカーディガン）の前に、蒼（黒いパーカー、中学生の男の子）が目をそらしたまま、くしゃくしゃのプリントを片手で差し出している。愛奈は目をまるくしてフリーズ。うしろで哲（黒ぶちメガネ、グレーのパーカー）が「あっ」という顔で自分のおでこに手を当てている。室内なので全員靴なし（靴下・スリッパ）。ジブリ映画のような手描きアニメ、水彩タッチ。全員の顔が見えるように、頭の上に少し余白。縦長（9:16）、文字は入れないでください。手は1人2本ずつ。
```

