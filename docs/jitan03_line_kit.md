## 構成
| 秒 | 映像 | 声・文字 |
|---|---|---|
| 0〜2 | 絵1：ソファでスマホを書いては消す愛奈 | 文字「部活の保護者LINE、お礼の一文に30分…」 |

- 絵1は哲がのぞきこむ形。絵2は11/10の「にっこりの愛奈」を使い回せる

## 絵（ChatGPT）
### 絵1：ソファでスマホに悩む愛奈と、のぞきこむ哲
```
添付の絵と同じ田中家のリビングの白いソファで、愛奈（ラベンダーのカーディガン）がスマホを両手で持ち、眉を寄せて文章を書いては消している。うしろから哲（黒ぶちメガネ、グレーのパーカー）がひょいっとのぞきこんで、軽い顔で何か言っている。夕方のやわらかい光。室内なので靴なし。ジブリ映画のような手描きアニメ、水彩タッチ。2人の顔が見えるように、頭の上に少し余白。縦長（9:16）、文字は入れないでください。手は1人2本ずつ。
```
