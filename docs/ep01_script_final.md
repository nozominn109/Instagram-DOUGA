# 第1話「読書感想文編」 リール用 決定台本（約35秒）

希さんの台本をもとに、リールで最後まで見てもらいやすい長さ・テンポに整えた版です。

## 長さとテンポの考え方

- **目標：約35秒**（最初の台本の28〜32秒に近づけつつ、話の流れは全部残す）
- **声のテンポ：1.2倍**（声の高さは変えずに速さだけ上げる。ElevenLabsで普通に作った声を、仕上げのときに私が速くします）
- **場面の切り替えは1〜4秒ごと**（リールは2〜3秒ごとに画面が変わると離脱されにくい）
- **最初の2秒で「AIに宿題丸投げ！？」の見出し**を出して、続きを見たくさせる

## 元の台本から変えたところ（3か所）

| 場所 | 元の台本 | リール版 | 理由 |
|---|---|---|---|
| ママのお願いの仕方 | プロンプト全文を声で読む（約12秒） | 声は要点だけ。**全文はスマホ画面に文字で表示** | 全文を読むと12秒止まってしまうため。画面に出せば保存してもらいやすい |
| 莉奈「うん、これなら自分でも書けそう！」 | あり | **なし** | 後の「やばっ！すごい、これなら楽しく書けそう！」と同じ内容なので、ここで言うと山場が弱くなる |
| AIの返事 | 「はーい！初めまして、莉奈ちゃん。一緒に素敵な感想文を作ろうね！それじゃあ最初の質問です……」 | 「はーい！一緒に素敵な感想文を作ろうね！最初の質問です！」 | 全文はスマホ画面に表示。声は短くしてテンポを保つ |
