# 第1話「読書感想文編」 リール用 決定台本

**セリフは希さんの台本のまま、一字一句変えません。**（やり取りの言葉には意味があるため）
長さとテンポは、声の速さと画面の見せ方で調整します。

## 長さとテンポ

- **声のテンポ：1.2倍**（声の高さは変えずに速さだけ上げる。ElevenLabsで普通に作った声を、仕上げのときに私が速くします）
- **全体の長さ：約50秒の見込み**（セリフを全部入れるとこのくらい。リールは90秒まで問題なく投稿できます）
- 最後まで見てもらう工夫
  - 最初の2秒で「宿題をAIに丸投げ！？」の見出し
  - 1〜4秒ごとに画面を切り替える（話す人のアップ、リアクション、スマホ画面）
  - ママのプロンプトの場面は、話すのに合わせて**スマホ画面に文字が打ち込まれていく**＋大事な言葉に**マーカー**（保存したくなる場面にする）
