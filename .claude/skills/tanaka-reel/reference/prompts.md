## ChatGPT：新しい絵（基本の形）

```
添付の絵と同じ田中家の<場所>（<変えてはいけないもの：家具の位置・窓・席順など>は変えないでください）。<時間：夜9時で、窓の外は夜景（スカイツリーが光っている）など>。<人物1（見た目を毎回書く）>が<ポーズと表情>。<人物2>が<…>。<ほかの家族は画面に入れないでください／足もとにチャッピー など>。室内なので全員靴なし（靴下・スリッパ）。ジブリ映画のような手描きアニメ、水彩タッチ。<顔が見えるように、頭の上に少し余白>。縦長（9:16）、文字は入れないでください。手は1人2本ずつ。
```

人物の見た目（毎回書く）：
- 愛奈：明るい茶髪ふんわりウェーブ、少し切れ長の落ち着いた目元、ラベンダーのカーディガン（40歳くらい。莉奈の姉に見えないように）
- 哲（パパ）：黒ぶちメガネ、こめかみに少し白髪、うっすら無精ひげ、グレーのパーカー
- 蒼：黒髪ぼさぼさ、黒いパーカー、中学1年生（ChatGPTに止められたら学年を外す）
- 莉奈：茶髪ポニーテールにピンクのシュシュ、ピンクのトレーナー
- 希亜：ピンクのロンパース、ピンクのリボンのヘアバンド（ベビーチェア）
- チャッピー：クリーム色のトイプードル、ラベンダーの首輪

## ChatGPTに止められたとき（コンテンツポリシー）

- 「小学5年生」「13歳」など**年齢・学年の言葉を外す**。「お母さん」「女の子」のように言いかえる。
- 指示を短くする。それでもだめなら「添付の絵なしで」貼ってもらう。

## マークアップ（部分修正）の形

```
<直す所>を<こうしてください>。<変えないでほしいもの：顔・表情・服・ほかの人物・部屋・夜景>は変えないでください。
```

よく使った直し：
- 腕が長く伸びる（テーブルの下のスマホ）→「腕を自然な長さにして、スマホはテーブルのふちのすぐ上で、胸の前に近い高さで両手で持つ（テーブルの下に伸ばさない）」
- 手が3本 →「手を2本だけにしてください。あごの手は消して、両手でスマホを胸の前で持つ」
- 食器の数（お味噌汁が6つ）→「手前の左はしと右はしの2つのお椀を消して、その場所は何もない木のテーブルに。4人分だけ残す」
- 靴がテーブルの上 →「シューズの袋を消して、床の上の蒼の足もとに置く」
- スマホの裏に変な柄 →「スマホの裏側を、無地のやわらかいピンクベージュ色に。カメラの丸い穴は残す」
- 表情が大げさ →「驚きすぎない。あっ！と気づかされた自然な顔」／怒り顔 →「眉をきゅっとつり上げ、目はまっすぐ相手を見る。口はきびしく小さく開けて強めに言っている（怒鳴らない）」
- 教科書 →「日本の小学校の国語の教科書：縦長の薄いA4の冊子、うすい水色の表紙、上に白い帯に『国語』、小さな鳥と葉っぱのイラスト」
- コンビニに行く服 →「ショート丈のダウン、マフラー、ゆったりしたパンツ、スニーカー。バッグは持たない」（帰宅後の部屋着も同じパンツにそろえる）

マークアップのボタンが出ないときは：絵をクリックして大きく開くと、右上に「選択」（筆のマーク）。それでも出なければ、入力欄に直しの文を貼って送るだけでもよい。

## Kling（画像から動画・2.5 Turbo・1080p・5秒）

```
<人物>が、<動き・表情の変化>。<ほかの人物は〜のまま>。口を動かすのは<話す人>だけ。カメラは固定。ジブリ映画のような手描きアニメ、水彩タッチ。
```

- しゃべらない場面：「全員、口は閉じたまま、しゃべらない」
- 歩く場面：「カメラは2人のうしろから、同じ速さでゆっくりついていく」
- 湯気・髪・ランプなど小さな動きを1つ入れると、止まって見えない。
- 料金の目安：2.5 Turbo 1080p は25クレジット（4.0は75）。プロプランのままで足りる。足りないときは660クレジット（10ドル）の都度購入を案内。
