# 仕上げ（編集）のしかた

## 道具

| やること | コマンド |
|---|---|
| 新しい環境の準備 | `python3 scripts/tools.py setup` |
| 届いた声を調べる | `python3 scripts/tools.py voices <mp3…>` |
| 言い直しを切る | `python3 scripts/tools.py trim 入力 出力 --start 1.2 [--end 3.4]` |
| 蒼の声の加工 | `python3 scripts/tools.py sora 入力 出力 [--start 秒] [--end 秒]` |
| 音量を見る | `python3 scripts/tools.py level <mp3…>`（目安 −20dB前後） |
| コマを並べて見る | `python3 scripts/tools.py sheet 動画.mp4 一覧.png [--fps 1.4 --cols 10 --crop W:H:X:Y]` |
| 1コマ見る | `python3 scripts/tools.py frame 動画.mp4 秒 出力.png` |
| チャットの絵を保存 | `python3 scripts/tools.py webp <images/〇〇.webp> output/<回>/keyframes/<名前>.png` |
| 表紙 | `python3 scripts/tools.py cover 絵.png 表紙.jpg --line "文字:大きさ:色" --line … --y 1130` |
| 一覧（3:4）での見え方 | `python3 scripts/tools.py grid 表紙.jpg 確認.png` |
| 投稿ライブラリへ | `python3 scripts/tools.py publish "<フォルダ名>" --video … --cover … [--caption …]` |

一覧画像や確認用の画像は、スクラッチパッドに書き出して `Read` で見る（希さんには送らない）。

## ひな形スクリプト

- ショート（10〜20秒・会話＋スマホ相談）：`scripts/short_template.py` をコピー。11/23「上の子ばっかり怒っちゃう」と同じものが出る。
- 保存版（型・ポイントを並べる30秒前後）：`scripts/hozon1120.py`（ラベル `banner_top` / `banner_left`、まとめ画面 `summary`、元の素材から作り直すスマホ画面）。
- スマホ画面：`render.phone_screen(layer, t, msgs, header_note, rot_k)`。msgs は `("me"|"ai", 文, 表示する文字数, 強調する言葉, 強調の進み)`。header_note を `""` にすると上の見出しが出ない。
- 家族グループのチェックリスト画面：`scripts/chk1118.py` の `group_screen`。
- 文字：`short_ai_ok.text_block(f, [(文, 大きさ, 色)], y, lt, t0, cx, instant)`。**タイトルは `instant=True`**（動きなしで最初のコマから全部見える）。
- 字幕：`assemble_ai.sub_img(話す人, 文)`。吹き出し：`short_yuhan.bubble(f, 文, lt, y, 色)`。
- しゃべらない人の口が動くとき：`scripts/jitan_print.py` の `quiet_papa`（その人の頭〜手を1コマで止める）、`scripts/ep02.py` の `aina_only`（話す人だけ動かす。動かす範囲を顔と体だけにせまくしないと二重に見える）。どちらもだめなら、話す人1人のアップの絵を作ってもらう。
- 昼の窓を夕方に：色をいじるより、**絵を作り直してもらって静止画＋ゆっくり寄せる**（`yomi1119.py` の `still_frames`）。

## テンポの基準（希さん・計画の会話で決まったこと）

- 月〜木のショート：10〜15秒がめやす（実際は声がのびて16〜20秒になりやすい）。金：30〜35秒（山場は25秒前後）。
- 声の速さ：ショートは1.2〜1.5倍。冒頭の導入・締めの大事なセリフは少しゆっくり（1.0〜1.4倍）。型や説明を並べる所はきびきび（1.5倍）。
- 最初の3秒に「具体的な困りごと＋問い」。タイトルは0秒目から（約1秒〜。セリフ字幕と同時に出さない）。
- 大事な1行（AIの答えなど）は大きな字幕で2秒以上（「1秒長め」）。
- 保存バナー「全文はキャプションに。保存してね」は中盤に1回。大事なセリフの場面・冒頭3秒には出さない。
- 文字だけの場面・同じ絵が続く場面は短く（1.5〜2.5秒）。読む時間（例文・チェックリスト・まとめカード）は削らない。
- 最後のセリフのあと0.5〜0.9秒の余韻 → エンドカード（セリフにかぶせない）。余韻ではBGMを少し下げてもよい。
- 動画（5秒）が足りないときは、最後のコマをごくゆっくり寄せて止まって見せない。

## 画面の安全な範囲

- 上の約15〜18%（アカウント名）、下の約25%（y≒1437より下）、右端（いいね等）に大事な文字を置かない。
- ロゴは左上（x=30, y=300、`small_logo()`）。人物の頭にかからないか確認。
- タイトル・ラベル・字幕は**人物の顔・頭・口元にかけない**。スマホ画面の見出しにもかけない。
- 表紙のタイトルは横幅の中央90%以内、顔に重ねない。ロゴの位置と色（青→ピンク）はシリーズでそろえる。

## 書き出しで気をつけること

- 書き出しは数分かかる。バックグラウンドに回されたら、`pgrep -f scripts/<回>.py` で終わるのを待つ。**同じスクリプトを2つ同時に動かさない**。
- 書き出したら必ず `sheet` で通して見る。直したところは `frame` で拡大して確かめる。
- できた動画は `output/<回>/<回>.mp4`。投稿ライブラリの `最終版.mp4` も差しかえる（publish）。
