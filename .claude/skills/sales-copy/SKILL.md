# 自分の文体で書くセールス文・案内文

LINE配信文・案内文・告知・メルマガ（単発／ステップ）・LP・イベントや講座の募集文を、**書いた本人が1文字も直さずに出せる**ところまで仕上げる。
口調や改行を真似るだけでなく、**その人の立ち位置と価値判断ごと**そろえる。「自分っぽくない」の原因は、たいてい口調ではなく立ち位置のズレ。

## 必要なもの（最初に確認し、無ければそろえる）

- Claude Code だけで動く
- あなたの文体メモ（ナレッジベースにあれば先に読む。無ければ手順1で作る）
- 書く対象の事実：何を・誰に・いつ・いくらで・どう申し込むか（分からない項目は推測で埋めず、聞く）

## 最初にこう言う

- 「案内文作って」
- 「LINEの配信文を書いて」

## 手順

### 1. 文体メモを読む（無ければ作る）
- ナレッジベースに文体メモ・プロフィール・過去の配信文があれば、先に読む
- 無ければ、過去に自分で書いて手応えのあった文章を**3本**もらう（できれば媒体違い：LINE・メール・SNS投稿など）
- 3本から次を抜き出して文体メモにする
  - 一人称、語尾（です・ます／言い切り）、一文の長さ、改行・空行の入れ方
  - 呼びかけ方、よく使う言い回し、たとえ話の癖、数字の出し方、絵文字・記号の量
  - **使わない言葉・言い方**（NGリスト）
  - テーマごとの立ち位置（手順3）
- 作った文体メモは、本人の了承を得てナレッジベースに保存する。次からは読むだけで済む

### 2. 設計を固める（1問ずつ聞く）
お題がふわっとしていたら、書き始める前に次を埋める。**一度に全部聞かず、1問ずつ**聞く（範囲を絞ると答えやすい）。
- ゴール：読んだ人に何をしてほしいか（1文で。例：説明会の申込・返信・購入）
- ターゲット：誰の、どんな状態の、どんな悩み・欲求か
- オファー：何を、いくらで、なぜ今か
- 約束と証拠：読むと何が得られるか、その裏付け（実績・事例・数字）
- 買わない理由と、それへの答え
- 次の一歩：申込方法・締切・問い合わせ先
- 媒体と長さ

設計が決まっていれば、それを使う。お題そのものが無ければ、何を書きたいかを1問だけ聞く。

### 3. 立ち位置を1つ選ぶ
同じ人でも、テーマによって立ち位置が変わる。書く前に1つ決めて、最後までぶらさない。
- **先生**：自分が成果を出した領域。事例と数字で引っぱる。言い切ってよい
- **伴走**：これから挑戦する人と一緒に向かう。上から教えない。途中経過を見せること自体に価値がある
- **実験者**：まだ答えが出ていない領域。「試している途中」を正直に出す
- **後輩**：相手が目上・格上。先に立ち位置を下げ、自分の得意な一点だけは堂々と語る

**視点のズレに注意。** 挑戦の途中の話を、成功した後の目線で書かない。伴走のテーマで先生の口調が出ると、一気に本人らしさが消える。

### 4. 型を決める
- 同じ用途で反応が良かった実物（自分の過去の配信、よく読まれている他の人の文章）を2〜3本見て、型を1行で決めてから書く
- 構成の定石（問題提起→共感→解決→証拠→行動 など）は使ってよい。ただし**型に本人の考えを従わせる**。型を優先して本人らしさを消さない

### 5. 下書きする
- 文体メモの語尾・改行・言い回し・たとえ話を反映する
- 具体を入れる：数字・事例・日時・場所。数字は確かめたものだけ使う
- 媒体ごとの形（下の「媒体ごとの形」）で出す

### 6. 自己点検（「1文字も直さず出せるか」）
- [ ] 立ち位置が最初から最後までぶれていない
- [ ] 文体メモのNGが混ざっていない
- [ ] 本人の価値判断と矛盾していない
- [ ] ゴール・オファー・証拠・次の一歩がそろっている
- [ ] 下の「書かないこと」に引っかかっていない
- [ ] 声に出して読み、本人が言いそうにない一文がない

引っかかったら直してから出す。

### 7. 出す・保存する
- 本文と一緒に「立ち位置／ゴール／点検結果」を1〜2行で添える
- 配信文はそのまま貼れる形で出す（件名・本文・申込先）
- 確定版はナレッジベースに保存する。本人が直した箇所は文体メモに戻す（次の精度が上がる）

## 媒体ごとの形

- **LINE配信**：通知や一覧に出る冒頭1〜2行で開くかが決まる。用件を先に。スマホで読む前提で短く改行する
- **メルマガ**：件名案を2〜3本。本文の冒頭で用件を言う。1通1用件
- **ステップメール**：先に1通ずつのゴールを並べてから、通し番号で本文を出す
- **LP**：見出し→悩み→解決→証拠→オファー→よくある質問→申込、の順にセクションごとに出す
- **募集文・告知**：日時・場所（オンラインか）・対象・定員・費用・申込方法・締切を必ず入れる。抜けていれば聞く

## 書かないこと（実際に直された教訓）

- **盛らない・煽らない**：「残りわずか」「今だけ値引き」で急かさない。値引きで集めると、次も値引きが要る
- **「今◯人しかいない」と書かない**：少なさは盛り上がっていない印象になる。素直な案内文のほうが届く
- **欠点や「無いこと」を見出しにしない**：同じ事実でも「何ができるか」の側から言う。否定形で価値を説明しない
- **聞かれていない段落を足さない**：経緯・進捗・気遣いの前置きは要らない。用件が1つなら1つだけ書く。長い下書きは、結局本人が削って送ることになる
- **相手を不安にさせない**：こちらの不手際は原因を並べず、直した結果と次の一手だけ書く
- **履行できない選択肢を出さない**：実際には受けられない日程・特典・対応を並べない
- **個別の連絡では、こちらから日付を指定しない**：相手の都合を聞く。未確定の予定を確定扱いにしない
- **やっていないことを「やってみた」と書かない**：体験談や「こうなった」は、実際にやった事実だけ
- **増える・減る件数を長く残る物に焼かない**：LPや固定の案内に「◯本」「◯人」と書くと、変わった瞬間に嘘になる。「増えていきます」と書く
- **内部の数字・未確定の話を出さない**：会員の減少・解約・残高・原価・報酬、交渉中や審査中の案件。スクショで外に出ても困らないかで判断する
- **メール本文にMarkdownを書かない**：「**」「#」は記号のまま見える。強調は改行や「■」で表す
- **送信元で誰か分かるなら、名乗りを繰り返さない**：署名は名前・肩書・メール・URL程度。住所や電話は、相手が必要なときだけ本文に書く

## うまくいかないとき

- 「自分っぽくない」と言われたら、口調より先に**立ち位置と価値判断**を疑う
- 直しが入ったら理由を聞き、文体メモのNGや言い回しに1行足す。同じ直しを2度させない
